Open source

Things I build in the open

Rust-first projects across ML, LLM systems, Kubernetes tooling and developer agents. Most live under the neurono-ml org.

🧭 typed-lm

Single-forward-pass semantic routing in Rust: turns dense LLMs into a typed decision API: booleans, choices and scores instead of generated text. Built on Candle, with LoRA/QLoRA training and FP8/FP4 quantization.

RustLLMsCandle
GitHub ↗
🧪 sciencekit

A classical machine learning library, similar to scikit-learn, written and optimized in Rust. Zero-copy APIs, pluggable execution (CPU/SIMD/BLAS/GPU) and native out-of-core processing, with Python bindings via PyO3.

RustMLPyO3
GitHub ↗ Docs ↗
📦 serde-onnx

Serde-first ONNX intermediate representation in Rust with a generated protobuf codec and typed ai.onnx.ml operator bindings. Pure Rust, no C/C++ dependency.

RustONNXSerde
GitHub ↗ crates.io ↗
☸️ k8s-maestro

Type-safe Kubernetes workflow orchestration in Rust. Define multi-step workflows with a fluent API: DAG dependencies, parallelism, retries, checkpointing, RBAC and network policies.

RustKubernetesMLOps
GitHub ↗ crates.io ↗
🐇 rabbitmq_streamer

Rust library wrapping RabbitMQ publish/consume behind streams: high-level APIs, manual acks, automatic reconnection and exponential backoff, tested against real brokers.

RustRabbitMQStreams
GitHub ↗ crates.io ↗
🥒 cucumber-openspec

Deterministic converter from OpenSpec spec.md behavior specifications into Cucumber/Gherkin .feature files in 80 languages, with zero AI. Keeps specs and tests in sync via CI.

BDDCucumberTypeScript
